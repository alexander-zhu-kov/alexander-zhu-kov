### Программа «Завод в цифрах» — версия 0.5.5

**Что это.** Экран показателей завода для собственника, директора и директора по персоналу: производство, качество, финансы и люди
в одном месте. Ставится на компьютер предприятия (Windows и Mac), открывается в браузере, работает без облака.

**Для чего.** Чтобы видеть отклонение в тот день, когда оно возникло, а не в отчёте за месяц, — и знать, кто и что с ним делает.

**Как работает.** Читает файлы Excel, которые завод уже ведёт: выпуск, журналы ОТК и простоев, бюджет, персонал. Формы не меняются,
второй раз данные никто не вводит. По показателю вне цели владелец называет **три главные причины** (программа подсказывает их из данных),
по каждой назначает **действие с ответственным, сроком и статусом**, а через месяц видно, что стало с показателем и повторилась ли причина.

```
Файлы Excel ──► показатель и цель ──► отклонение ──► ТОП-3 причины ──► действие: кто и когда ──► статус ──► эффект через месяц
```

**Что даёт бизнесу.** Одни цифры у всех руководителей; решения с ответственным и сроком; видно, какие действия помогли;
брак, простои и текучесть стоят рядом с себестоимостью, EBITDA и чистой прибылью; сводку к совещанию не собирают вручную.

**P&L** по месяцам: факт к бюджету и прогнозу, EBITDA, чистая прибыль, рентабельность. **Персонал:** численность, текучесть, выработка на человека, доля ФОТ в выручке.

**Новое в версиях 0.5 — доверие к числам:** загруженное сверяется с итогом файла; план не смешивается с фактом, прошлый год — с текущим;
отчёт о прибыли прямо пишет, по каким расходам данных нет; у цели указано, откуда она взята; у каждого файла — журнал изменений.
Необычный файл настраивается один раз за пять шагов, читаются русские и английские формы. 355 автотестов перед каждым выпуском.

**Для любой отрасли.** Программа работает с показателями, а не с технологией. Есть библиотека готовых форм Excel: 123 показателя по 15 блокам компании —
от закупок и входного контроля до продаж, сервиса и финансов; предприятие выбирает нужные, программа читает их без настройки.

**Что дальше.** Настройка визуализации (вид графика из списка: линия, столбцы, план и факт, кольцо, спидометр) и подключение ИИ как необязательной функции
на компьютере предприятия: подсказки при настройке файлов и черновик текста к совещанию; числа считает программа.

### Программа «План-факт» — версия 3.3.1

Контроль производства для руководителя: план по дням и факт по сменам с причинами отклонений, планёрка по шагам с протоколом,
мероприятия с ответственным и сроком, заказы и готовность к отгрузке, план по ресурсам с проверкой «что если», качество (ОТК), простои по QR-кодам, время операций.
Ставится на компьютер предприятия (Windows и Mac) и работает в локальной сети без облака.

**Как устроена**

```
Браузер / телефон / QR ──► Сервер в сети предприятия (Python) ──► SQLite
                             права: 14 разделов × 6 должностей      миграции схемы, ежедневные копии,
                             проверки и расчёты на сервере          точки восстановления
Excel (импорт, шаблоны) ──┘  модули включаются лицензией (Ed25519)
GitHub Actions ──► 314 автотестов ──► установщик Windows + архив Mac ──► проверка обновлений в программе
```

**Как росла:** 1.0 ввод факта и причин → 2.0 план по дням и загрузка форм → 2.1 установщик и лицензии → 2.3 модуль ОТК →
2.5 время операций → 2.7 простои по QR → 3.0 планёрка и права → 3.1 сборка для Mac и обновления → 3.2 отмена действий и доработка →
3.3 заказы и готовность к отгрузке →
**3.3.1 план по ресурсам: загрузка форм и линий, календарь, «что если»**. Дальше: модуль «Отгрузки» и себестоимость.

Код программ закрыт — это коммерческие продукты. Живую работу показываю на встрече.
