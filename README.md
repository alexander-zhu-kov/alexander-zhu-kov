### Программа «План-факт» — версия 3.3.1

Контроль производства для руководителя: план по дням и факт по сменам с причинами отклонений, планёрка по шагам с протоколом,
мероприятия с ответственным и сроком, заказы и готовность к отгрузке, план по ресурсам с проверкой «что если», качество (ОТК), простои по QR-кодам, время операций.
Ставится на компьютер предприятия (Windows и Mac) и работает в локальной сети без облака.

**Как устроена**

```
Браузер / телефон / QR ──► Сервер в сети предприятия (Python) ──► SQLite
                             права: 14 разделов × 6 должностей      миграции схемы, ежедневные копии,
                             проверки и расчёты на сервере          точки восстановления
Excel (импорт, шаблоны) ──┘  модули включаются лицензией (Ed25519)
GitHub Actions ──► 314 автотестов ──► установщик Windows + архив Mac ──► проверка обновлений в программе
```

**Как росла:** 1.0 ввод факта и причин → 2.0 план по дням и загрузка форм → 2.1 установщик и лицензии → 2.3 модуль ОТК →
2.5 время операций → 2.7 простои по QR → 3.0 планёрка и права → 3.1 сборка для Mac и обновления → 3.2 отмена действий и доработка →
3.3 заказы и готовность к отгрузке →
**3.3.1 план по ресурсам: загрузка форм и линий, календарь, «что если»**. Дальше: модуль «Отгрузки» и себестоимость.

Код программы закрыт — это коммерческий продукт. Живую работу показываю на встрече.
